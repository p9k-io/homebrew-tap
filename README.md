# p9k-io Homebrew tap

Casks for the software [p9k-io](https://github.com/p9k-io) publishes.

## Agent Activity Monitor

A native macOS app that shows which processes exist because of AI coding agent sessions, what is heating your Mac right now, and what can safely go. Source and documentation: [p9k-io/agent-activity-monitor](https://github.com/p9k-io/agent-activity-monitor).

```sh
brew install --cask p9k-io/tap/agent-activity-monitor
```

Requires macOS 26 on Apple silicon. The cask installs the app and links its command line tool, `aam`. The app updates itself.
